# バックアップ・データ移行ガイド

このアプリのデータはブラウザの localStorage に保存されます。GitHub Pagesに公開しても、データはクラウド同期されません。

## なぜバックアップが必要か

localStorageは手軽ですが、以下の場合にデータが消えたり見えなくなったりする可能性があります。

- ブラウザのサイトデータを削除した
- キャッシュや閲覧データを削除した
- 別ブラウザを使った
- 別端末を使った
- プライベートブラウズで利用した
- ブラウザプロファイルを変更した
- 端末を買い替えた

重要な応募履歴や当選記録を残すため、定期的なJSONバックアップを推奨します。

## JSONエクスポートの手順

JSONは復元用のバックアップ形式です。

1. アプリを開きます。
2. 「バックアップ」タブを開きます。
3. 「JSONエクスポート」を押します。
4. `kensho-campaigns-YYYY-MM-DD.json` のようなファイルがダウンロードされます。
5. iCloud Drive、Google Drive、USBメモリなど、安全な場所に保存します。

## JSONインポートの手順

JSONインポートは現在のデータをインポート内容で置き換えます。

1. アプリを開きます。
2. 「バックアップ」タブを開きます。
3. 「JSONインポート」でバックアップファイルを選びます。
4. 確認ダイアログを読み、問題なければ続行します。
5. インポート後、一覧や応募履歴が復元されているか確認します。

## CSVエクスポートとの違い

| 形式 | 主な用途 | 復元に向くか | 備考 |
| --- | --- | --- | --- |
| JSON | バックアップ、端末移行、復元 | 向いている | アプリのデータ構造を保持します |
| CSV | 閲覧、表計算、集計、印刷 | 向いていない | ExcelやGoogleスプレッドシートで見やすい形式です |

CSVはBOM付きUTF-8で出力されるため、日本語を含むデータをExcelやGoogleスプレッドシートで開きやすくしています。

復元目的ではJSONを使ってください。

## バックアップ頻度の目安

- 毎日よく使う場合: 週1回
- 応募履歴や当選記録を大切に残したい場合: 応募作業後
- 端末変更前: 必ず実施
- ブラウザのデータ削除前: 必ず実施
- 大量にインポート・編集する前: 事前に実施

## 端末変更時の移行手順

1. 旧端末でアプリを開きます。
2. 「バックアップ」タブからJSONエクスポートします。
3. JSONファイルを新端末へ移します。
4. 新端末でアプリを開きます。
5. 「バックアップ」タブからJSONインポートします。
6. キャンペーン一覧、応募履歴、タグ、メモが移行されているか確認します。

## スマホとPC間でデータを移す手順

PCからスマホへ移す場合:

1. PCでJSONエクスポートします。
2. AirDrop、クラウドストレージ、メール添付などでスマホへ送ります。
3. スマホで公開URLを開きます。
4. 「バックアップ」タブからJSONインポートします。

スマホからPCへ移す場合:

1. スマホでJSONエクスポートします。
2. ファイルアプリ、クラウドストレージ、メール添付などでPCへ送ります。
3. PCでアプリを開きます。
4. 「バックアップ」タブからJSONインポートします。

## インポート前の注意

- インポートすると現在のデータは置き換えられます。
- 必要ならインポート前に現在データをJSONエクスポートしてください。
- 不正なJSONや想定外の形式は読み込まれません。
- URL、日付、タグ、ステータスなどはアプリ側で検証・正規化されます。
- インポート後は、リスク判定、スコア、コメント案が再計算されます。

## 全削除前の注意

「全データ削除」は元に戻せません。

削除前に以下を確認してください。

- JSONエクスポートを済ませた
- ダウンロードしたJSONファイルを開ける場所に保存した
- 別端末へ移行する必要がないか確認した
- 当選履歴や応募後メモが失われても問題ない

## バックアップファイルの扱い

バックアップJSONには、キャンペーン名、URL、メモ、応募履歴、当選結果などが含まれます。

- 個人情報をメモに書いた場合、その情報もJSONに含まれます。
- 共有PCや公共端末にバックアップを残さないでください。
- 不要になったバックアップは安全に削除してください。
- クラウドストレージへ保存する場合は、共有設定に注意してください。

## 安全上の注意

バックアップ機能はデータの保存・復元だけを行います。SNSへのログイン、フォロー、リポスト、いいね、コメント、DM、投稿、外部フォーム送信などは行いません。

応募操作は必ず人間が手動で行ってください。
